# ⚡ ПРОВОДНИК

**Проводник** — это 2D-игра на чистом JavaScript с физикой цепи (Verlet Integration). Вы управляете точкой крепления, чтобы раскачивать груз и разрушать блоки.

## 🎮 Особенности

- ✅ Физика цепи в реальном времени
- ✅ Управление мышью и касаниями (Android)
- ✅ Система уровней (в разработке)
- ✅ Сохранение рекордов на сервере
- ✅ PWA-готовность для мобильных устройств

## 📦 Технологии

- **Фронтенд:** Vanilla JS, Canvas, CSS3
- **Бэкенд:** Node.js, Express
- **Физика:** Verlet Integration (собственная реализация)

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/game-project.git
cd game-project

# Установите зависимости сервера
cd server
