# ⚡ ПРОВОДНИК

**Проводник** — это 2D-игра на чистом JavaScript с физикой цепи (Verlet Integration). Вы управляете точкой крепления, чтобы раскачивать груз и разрушать блоки.

## 🎮 Игровой процесс

- **Управление:** Водите мышкой или пальцем по экрану — точка крепления следует за курсором
- **Цель:** Разрушить все блоки на поле
- **Физика:** Реалистичная цепь с инерцией и гравитацией
- **Прогрессия:** После разрушения всех блоков — переход на следующий уровень
- **Опасность:** Если слишком сильно растянуть цепь — она рвется!

## 📊 Особенности

### 🎯 Игровая механика
- **Физика цепи** — Verlet Integration с 14 точками
- **Рандомная генерация** — каждый уровень уникален
- **Система комбо** — быстрые удары дают бонусы
- **5+ типов блоков** — разные цвета и HP
- **Прогрессия уровней** — сложность растет с каждым уровнем
- **Разрыв цепи** — анимация падения груза

### 📱 Интерфейс
- **Главное меню** — кнопка старта, рекорд
- **Игровой HUD** — счет, уровень, таймер, комбо
- **Экран Game Over** — полная статистика
- **Адаптивный дизайн** — работает на ПК и мобильных

### 🏆 Рекорды
- Сохранение на сервере (Node.js + Express)
- Автоматическое обновление рекорда
- Хранение в JSON файле
